## 1. 巡检背景与架构审计发现

在对 `haier-ac-mac` v1.9.20 源码的全面审查与架构体检中，发现以下关键缺陷与高价值演进空间：

### 1.1 音频渲染空间化与硬件采样率漂移缺陷 (Audio Architecture)
- **问题描述**：`AmbientSoundEngine.swift` 在 AVAudioSourceNode 渲染回调中，直接采用单声道双写逻辑拷贝至立体声声道，且固定假设硬件采样率为 44100Hz 计算相位步长。当用户连接不同音频输出设备（如 Studio Display 48kHz、AirPods Pro 48kHz 或外接高保真 DAC 96kHz）时，音频周期与音高会出现严重失真与计算偏移；左右声道粉噪信号源完全同步，缺乏空间分离度与听感纵深。
- **修复方案**：
  1. 重构 CoreAudio 缓冲区写入逻辑，适配 CoreAudio 非交错双声道独立缓冲流（`ablPointer[0]`, `ablPointer[1]`）以及交错式流缓冲。
  2. 动态捕获当前硬件输出采样率 `outputFormat.sampleRate` 并计算动态倒数 `invSr`，使所有振荡器和正弦发生器精确匹配硬件频率。
  3. 解耦粉红噪声生成器，构建独立的左右声道两套独立滤波系数状态机（`b0L...b6L`, `b0R...b6R`）与 Brown 噪声漂移发生器，实现双耳去相关的真实自然声场。

### 1.2 多设备并发动力学能耗聚合缺陷 (Energy Analytics Engine)
- **问题描述**：原 `accumulateMinuteSample` 仅接收单一设备的模式和开关状态，当家庭环境中配置了多个空调（如客厅、主卧、书房）时，其他设备的能耗未能被纳入动力学积分，导致全屋能耗统计失真。此外，当系统休眠或调度延迟时，每分钟固定的 `1/60.0` 小时积分计算会导致电量与功率曲线失准。
- **修复方案**：
  1. 新增 `DeviceEnergySample` 结构体，支持多设备并发采样。
  2. 实现 `accumulateSample(deviceSamples: [DeviceEnergySample], elapsedSeconds: Double)`，根据真实流逝时间动态计算精确能量积分 `(power * deltaHours) / 1000.0`。
  3. 当所有空调关闭时动态显示待机微功耗，避免生成虚假运行时间。

### 1.3 56°C 蒸发器高温自清洁生命周期短板 (Self-Cleaning & Filter Care)
- **问题描述**：原自清洁逻辑仅存在于 `FilterCareSheet` 的局部状态中，用户一旦关闭维护弹窗，SwiftUI View 销毁导致自清洁倒计时 Task 中断，无法在后台持续进行，且未向用户发送系统完成通知；滤网维护累计时间未区分多设备。
- **修复方案**：
  1. 将自清洁完整生命周期提升至 `AppModel` 全局托管（`isSelfCleaningActive`, `selfCleaningRemainingSeconds`, `startSelfCleaning`, `stopSelfCleaning`）。用户关闭弹窗后后台继续计时，完成时通过 `UNUserNotificationCenter` 触发本地系统通知。
  2. 扩展滤网健康管理为多设备字典存储（`deviceFilterMinutes`, `deviceFilterCleanedDates`），支持分设备重置与监控。
  3. 在 `FilterCareSheet` 中增加多设备快速分段切换器。

### 1.4 全屋离家智能守护漏洞 (Network Presence Guard)
- **问题描述**：`NetworkPresenceGuard.triggerLeaveHomeAlertIfNeeded()` 此前只检测首个可用设备，当主设备未开而次卧空调仍运转时漏报。
- **修复方案**：遍历全部云端及局域网手动添加的空调设备，聚合所有仍处于开机状态的设备清单、当前温度与模式，发出合并告警通知。

### 1.5 菜单栏常驻交互与悬浮 Tooltip 状态感知扩展 (StatusItemController & Popover)
- **问题描述**：菜单栏图标悬浮提示内容单一，缺乏多维运行态指示；右键菜单缺乏助眠声学和自清洁快捷入口。
- **修复方案**：
  1. 在 `StatusItemController` 中添加响应式多维悬浮 Tooltip，实时呈现当前主控设备运转状态、设定与室内温度、自清洁剩余倒计时、运行中的睡眠曲线方案和白噪音播控状态。
  2. 右键菜单增加「助眠白噪音播放/暂停」与「滤网保养与自清洁」直达入口。
  3. Popover 控制中心面板增加自清洁进行中状态条与白噪音播放微卡片。
