# Adopt Hybrid macOS Control Center and Linear Design System

We chose to evolve the UI from pure flat Linear-style opaque surfaces into a hybrid design system combining macOS native translucency materials (`.ultraThinMaterial`) with Linear-inspired typography, hairline borders, and compact information density. Pure flat opaque palettes feel foreign in modern macOS popovers and windows, while standard Apple HIG alone lacks the high-density geek appeal suitable for power users; the hybrid provides native system cohesion with crisp developer-tool aesthetics.
